# Playbook: High-Retention MDW Matching (Singapore)

> Use with: Biodata Curator → Matching Consultant → Interview Assessor → Retention Analyst

## Goal
Maximise placements that survive **6 months** (reduce Rule 13A refunds and churn).

## Golden rules
1. Needs Brief before biodata  
2. One primary care-type per match  
3. Shortlist 3–5 only  
4. Conditional → Interview Pass (or written risk accept)  
5. Every early exit gets a mismatch code  

## 60-minute matching desk flow

| Min | Action | Agent |
|-----|--------|-------|
| 0–10 | Qualify care-type, urgency, rest day, languages | Matching Consultant |
| 10–20 | Complete Needs Brief + risk flags | Matching Consultant |
| 20–35 | Filter Matchable inventory | Biodata Curator |
| 35–50 | Scorecards + shortlist cover note | Matching Consultant |
| 50–60 | Book interviews for Conditional | Interview Assessor |

## Care-type hard gates

| Playbook | Interview required? | Typical hard fail |
|----------|---------------------|-------------------|
| Infant | Yes if newborn or first-time MDW | No infant evidence |
| Elderly | Yes if mobility/dementia | Housework-only history |
| General/cooking | Optional unless Conditional | Cuisine refusal + no training time |
| Dual-role | Yes — split assessment | Unpaid overload / no rest day |

## Handoff packet to Compliance (IPA)
- [ ] Needs Brief  
- [ ] Chosen scorecard (≥3.2 or accepted risk)  
- [ ] Assessor Report if Conditional  
- [ ] Employer confirmation answers  
- [ ] Consent notes for any shared biodata  

## Weekly matching QA
Retention Analyst reviews exits → update hard fails / weights → Curator tag fixes.

## Anti-patterns
- Flooding 15 PDFs on WhatsApp  
- “Any nationality OK” with unspoken preferences  
- Skipping rest-day discussion  
- Filing IPA on a Conditional without interview
