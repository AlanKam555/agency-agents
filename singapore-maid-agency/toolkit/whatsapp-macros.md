# WhatsApp macros (EN + 中文)

Edit bracketed fields. Add your **EA full name + licence number** in first replies where appropriate.

---

## 1) First reply / qualify

**EN**
```
Hi, thanks for contacting [EA NAME] (Licence No. [XXXX]).
To match the right helper, please reply:
1) Care need — infant / child / elderly / general / cooking
2) When you need her
3) First-time employer? Yes/No
We’ll follow up shortly. Fee details are shared during consultation on request.
```

**中文**
```
您好，这里是 [中介全名]（牌照号码 [XXXX]）。
为了更准确配对，请回复：
1）需要：婴儿 / 小孩 / 老人 / 家务 / 煮食
2）大概需要的时间
3）是否首次雇请女佣？是/否
顾问稍后联系您。服务收费说明可在咨询时按要求提供。
```

---

## 2) After qualification — book consult

**EN**
```
Thanks — noted [elderly care], timeline [2–3 weeks], first-time [Yes].
Next step: a short consult (15–20 min) on job scope, rest day, and budget range.
WhatsApp call or Zoom — which do you prefer, and what time works today/tomorrow?
```

**中文**
```
收到——护理类型：[照顾老人]，时间：[2–3周]，首次雇请：[是]。
下一步：15–20分钟沟通工作范围、休息日与预算范围。
方便今天/明天语音还是视频？请给两个时段。
```

## 3) Send shortlist (after Needs Brief)

**EN**
```
Based on your needs ([elderly / wheelchair assist], Mandarin preferred, Sun rest day), here are 3 fits — not a long biodata dump:
1) [Name/Ref] — why fit
2) [Name/Ref] — why fit
3) [Name/Ref] — why fit (conditional on video interview)
Please answer: [confirmation question]. Then we proceed to documents.
```

**中文**
```
根据您的需求（[老人护理/需协助行动]、偏中文、周日休息），我们精选 3 位：
1）[姓名/编号] — 适合原因
2）[姓名/编号] — 适合原因
3）[姓名/编号] — 适合原因（需视频面试）
请先确认：[确认问题]。确认后我们再走文件流程。
```

## 4) Day-7 check-in

**EN**
```
Hi [Employer], Day-7 check-in for [Helper].
1) What’s going well?
2) Any task that still needs training?
3) Any rest-day or communication issue?
We’ll also check in with her separately if needed.
```

**中文**
```
您好 [雇主]，这是 [女佣] 上工第 7 天回访：
1）目前哪些比较顺利？
2）还有哪项需要再培训？
3）休息日或沟通有问题吗？
如有需要，我们也会单独了解女佣情况。
```

## 5) Decline public fee question in chat ads / comments

**EN**
```
Thanks for asking. We share the full fee schedule privately during consultation so we can match your care needs properly. WhatsApp us your care type (infant/elderly/general) and timeline — we’ll advise from there.
```

**中文**
```
感谢询问。完整收费我们会在一对一咨询时说明，以便按护理需求匹配。
请私信告诉我们：护理类型（婴儿/老人/家务）和需要的时间，我们再详细说明。
```

## 6) Early termination — notify path

**EN**
```
Sorry it’s not working out. Please don’t cancel/repatriate yet — notify us first so we can advise on replacement vs refund options under your agreement and MOM rules. Share: start date, main issues, and whether you want a replacement.
```

**中文**
```
很抱歉目前不太顺利。请先不要急着取消准证/遣返——请先通知我们，以便按合约与 MOM 规定说明更换或退费选项。
请提供：上工日期、主要问题、是否希望更换。
```
