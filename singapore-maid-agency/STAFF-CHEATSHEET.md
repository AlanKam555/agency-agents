# Staff cheatsheet — who opens what

One page for branch staff. Pin this in your team WhatsApp / Notion.

| My desk | Open first | Then | Never |
|---------|------------|------|-------|
| **Owner / KAH** | [EA Operations Manager](singapore-maid-agency-ea-operations-manager.md) + [weekly KPI](toolkit/weekly-kpi.md) | Retention Analyst | Public fee ads |
| **Sales** | [Lead qualification](toolkit/lead-qualification.md) + Sales Closer prompt | Employer Advisor (first-timers) | Send biodata before Needs Brief |
| **Matching** | [Needs Brief](toolkit/employer-needs-brief.md) + Matching Consultant | Interview Assessor if Conditional | Shortlist >5 / hide job history |
| **Docs / WP** | MOM Compliance Officer | Placement Coordinator | Skip SIP / insurance before arrival |
| **Support** | [Day-7 check-in](toolkit/day7-checkin.md) | Replacement Specialist if failing | Coach illegal deductions |
| **Marketing** | [Ad compliance checklist](toolkit/ad-compliance-checklist.md) | Acquisition / Google Ads / SEO agents | Fee bait, “free replacement”, “obedient” |

## Copy-paste activations (English)

**Sales**
```
Activate Agency Sales Closer.
Lead: [paste WhatsApp]. Qualify care type, timeline, first-time Y/N. Draft reply. No public fees.
```

**Matching**
```
Activate MDW Matching Consultant.
Use Elderly/Infant/… playbook. Needs Brief + max 3 scorecards. Flag Critical risks.
```

**Ads**
```
Activate MOM Ad Compliance Reviewer.
Review this copy: [paste]. PASS/REVISE/BLOCK + compliant rewrite.
```
