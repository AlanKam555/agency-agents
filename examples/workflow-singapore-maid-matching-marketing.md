# Multi-Agent Workflow: Matching + Marketing for a Singapore Maid Agency

> Fill the pipeline with qualified employers, then match them so placements last past six months.

## The Scenario

Your licensed EA wants more **elderly-care** employer enquiries from Google/Facebook, fewer job-seeker tyre-kickers, and higher 6-month retention. Public fee ads were just flagged as risky — you need a compliant growth system tied to serious matching.

## Agent Team

### Marketing lane
| Agent | Role |
|-------|------|
| Employer Acquisition Marketer | Channel mix + funnel |
| MOM Ad Compliance Reviewer | Pre-flight creatives |
| Google Ads Lead Specialist | Search capture |
| Local SEO & Reputation Lead | GBP + reviews + landers |
| Employer Content Strategist | Education content |

### Matching lane
| Agent | Role |
|-------|------|
| Agency Sales Closer | Qualify inbound |
| Employer Advisor | First-timer cost/readiness |
| Biodata Inventory Curator | Clean helper inventory |
| MDW Matching Consultant | Score + shortlist |
| Interview & Skills Assessor | Gate Conditional matches |
| Match Retention Analyst | Close the learning loop |

## Phase 1 — Make marketing legal and targeted

**Activate MOM Ad Compliance Reviewer**

```
Activate MOM Ad Compliance Reviewer.

Audit these live assets: [paste ad copy / URLs / GBP posts].
Return PASS/REVISE/BLOCK with compliant rewrites.
Build a banned-phrase glossary for the sales/marketing WhatsApp group.
```

**Activate Employer Content Strategist + Local SEO & Reputation Lead**

```
Activate Employer Content Strategist.

Create an elderly-care hiring guide and 5 FAQ blocks (AEO-ready)
that explain matching/process without public fee amounts.
Include EA name + licence placeholder.

Activate Local SEO & Reputation Lead.

Map keywords and landing pages for elderly care + transfer intent.
Give a GBP weekly ops checklist and a Day-30 review request script.
```

**Activate Google Ads Lead Specialist + Employer Acquisition Marketer**

```
Activate Google Ads Lead Specialist.

Build campaign architecture for Brand + Generic hire + Transfer + Elderly care-type.
Provide compliant RSA examples and job-seeker negative keywords.
Primary conversion: qualified consult.

Activate Employer Acquisition Marketer.

Propose 30-day budget mix (Google/Meta/SEO/referral).
Design lead form fields that feed Matching (care type, timeline, first-time, language).
```

## Phase 2 — Make inventory match-ready

**Activate Biodata Inventory Curator**

```
Activate Biodata Inventory Curator.

We have 40 helper PDFs. Standardise into structured profiles with
care-type tags. Prioritise elderly=Y with evidence. Flag incomplete history as Hold.
```

## Phase 3 — Convert a real elderly-care lead

**Activate Agency Sales Closer → Employer Advisor → Matching Consultant**

```
Activate Agency Sales Closer.

Lead from Google Ads elderly campaign:
First-time employer, mother with mobility support needs, wants helper in 3 weeks,
English OK, Mandarin nice-to-have. No EOP yet.

Qualify and hand off.

Activate Employer Advisor.
Cost sheet + readiness for elderly care household; EOP reminder.

Activate MDW Matching Consultant.
Needs Brief using Elderly playbook. Shortlist max 3 with scorecards.
Mark Conditional if interview needed.
```

**Activate Interview & Skills Assessor**

```
Activate Interview & Skills Assessor.

Run elderly/caregiver script for Helpers #1 and #2.
Return Assessor Reports. Update recommendation for IPA.
```

## Phase 4 — Learn and reallocate budget

**Activate Match Retention Analyst**

```
Activate Match Retention Analyst.

Last 90 days: export placements with lead source + care-type + score + Day-90 outcome.
Which paid channels produce surviving elderly-care placements?
Recommend Matching hard-gate changes and Acquisition budget shifts.
```

## Success criteria
- All boosted ads have Compliance PASS  
- ≥80% leads tagged with care type  
- Elderly shortlists ≤3 with scorecards  
- Conditional matches interviewed before IPA  
- Budget shifts toward sources with better Day-90/180 survival
